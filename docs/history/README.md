# Development and release history

These documents preserve earlier investigations, measurements and release reviews.
Their version/status statements and shell examples describe historical checkouts;
use the [active documentation](../README.md) for current native 2.1 instructions.
Relative navigation is maintained, but archived execution paths and patch names
are provenance, not current installation recommendations.

- `0.x-and-1.0/`: Python-era UI/integration investigations and the old QML repair text.
- `2.1-development/`: native migration, session/power/held-key investigations,
  Phase 1 installer evidence and earlier architecture measurements.
- `releases/`: historical release notes, 1.0.1 review and old publication workflow text.

Historical Git tags and public assets are unchanged. The
[Phase 1 evidence](2.1-development/EZ-INSTALLER-PHASE1.md) remains explicitly staged
and includes its original file inventory. The current
[cleanup inventory](../maintenance/phase2-inventory.csv) records every baseline move.
